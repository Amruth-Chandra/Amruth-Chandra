#### ☁️ [AI-Based Cloud Operations Monitoring System](https://github.com/Amruth-Chandra/AI-BASED-CLOUD-OPERATIONS-MONITORING-SYSTEM.git)
A real-time cloud monitoring and alerting system with role-based dashboards for administrators and users/developers.
- Analyzes CPU, memory, latency, and error metrics — improved anomaly detection by 30% and reduced downtime by 25%
- ML models detect root causes (CPU overload, memory leaks, latency spikes), cutting troubleshooting time by 40%

**Tech Stack:** Python · SQL · HTML · CSS · JavaScript
🔗 [Live Demo](https://mps-project.onrender.com/) · [Repository](https://github.com/Amruth-Chandra/AI-BASED-CLOUD-OPERATIONS-MONITORING-SYSTEM.git)

#### 🛡️ UPIShield AI — *In Progress*
A real-time graph intelligence platform for detecting UPI fraud rings and coordinated fraud networks, going beyond traditional transaction-level detection.
- Models every UPI account as a node and every transaction as an edge in a graph database, using a **Graph Neural Network (GNN)** to learn patterns across the entire network instead of isolated records
- Assigns a real-time fraud risk score to accounts and transactions, with **Explainable AI** to justify why a transaction was flagged
- Streams live transactions through **Apache Kafka** into **Neo4j** for graph storage; **Spring Boot** exposes REST APIs consumed by a **React** dashboard showing suspicious accounts, fraud rings, and analytics in real time

**Tech Stack:** React · Spring Boot · Apache Kafka · Neo4j · Python · PyTorch Geometric (GNN) · MongoDB
